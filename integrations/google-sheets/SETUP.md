# Подключение планов самовывоза

Таблица уже создана: https://docs.google.com/spreadsheets/d/19fZ-bLDrnJ99Fl0NCMYmGoCMpF5bYbEvqN2iUJxIQvA/edit

1. Откройте таблицу → Расширения → Apps Script.
2. Замените содержимое `Code.gs` кодом из этой папки.
3. Добавьте HTML-файл с именем **Form** и вставьте содержимое `Form.html`.
4. В редакторе выберите функцию `initializeTiho` и запустите. Она обращается только к таблице из `SHEET_ID_`, устанавливает часовой пояс Москвы и создаёт ежечасное обновление сводки. Разрешение Google даёт владелец аккаунта.
5. Развернуть → Новое развертывание → Веб-приложение. Выполнять от имени владельца, доступ — **Все**, включая посетителей без Google-аккаунта. Опубликуйте веб-приложение. Саму таблицу оставьте закрытой.
6. Скопируйте адрес вида `https://script.google.com/macros/s/.../exec` в `window.TIHO_PLAN_FORM_URL` в `site-config.js`. Адрес `/dev` не подходит.
7. Откройте сайт с телефона без авторизации Google. Отправьте 2 коробки на завтра. Проверьте одну строку на вкладке «Заявки» и 2 коробки на завтра в «Сводке». Повторите на том же устройстве с 3 коробками: должно стать 3, а не 5. Проверьте отдельно сегодня. Тестовые строки удаляет владелец после проверки.
8. При изменении кода Apps Script обновляйте развертывание на новую версию; простого сохранения исходников недостаточно.

## Что хранится

Время записи по Москве, день получения, количество, сумма по 300 ₽, случайный ID. Имя, телефон и Telegram не запрашиваются. ID не является аккаунтом, не связывается с личностью; хранится в браузере по дням. Очистка данных браузера/другое устройство обходит защиту от повторов. Сервер принимает только сегодня/завтра и целое количество 1–20, обновляет запись под блокировкой и не возвращает посетителям общую таблицу.

## Ограничения

Это оценка спроса: покупатели могут не прийти. Нет оплаты, брони, Telegram-уведомлений, полноценной защиты от ботов. Приложение зависит от доступности Google и лимитов Apps Script. При недоступности сервер не должен показывать успех; на странице есть контакт для вопросов. Для начала достаточно смотреть вкладку «Сводка». Сводка обновляется при записи, открытии таблицы владельцем и ежечасным триггером.
