# Прототип приёма заявок

Это локальный экспериментальный сервер, НЕ готовый к публикации и работе с реальными персональными данными. Он не подключён к сайту. Понадобятся выбор и настройка инфраструктуры в РФ, HTTPS, защита от злоупотреблений, аудит и безопасный доступ к закрытому интерфейсу, мониторинг, управление резервными копиями и удалением, юридическая проверка и реальное тестирование. Встроенный WSGI-сервер разработки для публикации не использовать.

`app.py` содержит WSGI-приложение: проверка количества, телефона, даты сегодня/завтра по Москве, явного согласия и его версии; запись в SQLite; повтор по UUID не перезаписывает данные. API администратора поддерживает чтение и удаление с Bearer-токеном; сам по себе этот механизм не является готовой защищённой админ-панелью. Цена 300 ₽ рассчитывается на стороне представления и не хранится. Фактическое подтверждение заявки происходит вручную.

Переменные окружения: `TIHO_DB` — путь к базе вне публичного каталога; `TIHO_CONSENT_VERSION` — версия утверждённого текста согласия; `TIHO_ADMIN_TOKEN` — длинный случайный секрет, который нельзя записывать в репозиторий или в браузерный JS. Без версии согласия заявки отклоняются, без токена административный API закрыт. Временная база тестов создаётся вне проекта.

Сервер не содержит автоматической политики хранения, готового интерфейса оператора, защиты от массовых запросов или интеграции с главной страницей. Не подключать до завершения этих частей, настройки прав и проверки всей цепочки. Логи прокси и бэкапы тоже могут содержать персональные данные; их местонахождение и срок хранения необходимо установить. Не добавлять базу в Git.
