# Инструкции для разработчиков и ИИ-агентов

- Главный приоритет — лёгкий статический сайт, быстрая загрузка на телефонах и медленном интернете.
- Используйте HTML, CSS и JavaScript без сборки. Не добавляйте фреймворки, библиотеки, внешние шрифты, аналитику и тяжёлые эффекты без согласования с владельцем.
- Сжимайте фотографии, указывайте размеры изображений, используйте ленивую загрузку вне первого экрана. Не встраивайте фотографии в HTML через base64.
- Главный продукт — пальчиковая пахлава с кешью, исключительно коробками. Главная страница посвящена Сенному рынку, место № 8, возле конфет.
- Меню точки на Героя Сарабеева, 5к5 сохраняется в sarabeeva.html. Доставка временно скрыта по просьбе владельца.
- Не выдумывайте цену коробки, вес, часы работы рынка, состав, контакты и юридические реквизиты.
- Цена подтверждена владельцем: 300 ₽ за коробку. Текущая механика: анонимные планы самовывоза на сегодня/завтра, количество 1–20, без имени и телефона. Это ориентир спроса, не бронь. Запись идёт через Google Apps Script в закрытую Google Таблицу; повтор по тому же ID обновляет заявку. Не показывайте успех до ответа сервера. Пока URL в site-config.js пуст, отправка недоступна. Не заменяйте общее хранилище одним localStorage: в браузере хранится только ID для защиты от повторов. Telegram @danyanovich остаётся контактом для вопросов.
- Визуальное направление: винтажная кондитерская (60%) и современный экспериментальный интерфейс (40%). Симметрия, кремовый, пыльно-розовый, шалфейный, шоколадный, золотой; рамки, этикетки, номера секций. Без тяжёлого 3D. За 10–15 секунд должны быть понятны продукт, цена коробки и путь предзаказа.
- Сохраняйте существующие функции меню и адаптивность. При изменениях проверяйте мобильный вид, ссылки, консоль и размер ресурсов.

- Дополнительный референс владельца: https://hermes-agent.nousresearch.com — крупная типографика и контрастные элементы управления. Кремовая пастель и симметрия остаются основой; синий используется как акцент кнопок и интерфейса. Основной текст 18 px на компьютере / 17 px на телефоне; важные подписи не делать мелкими.
