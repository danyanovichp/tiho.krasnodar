# Green Corner

## Как запустить

Это автономный статический сайт. Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Короткие правила проекта

- Главный приоритет — быстрая загрузка и лёгкая работа на телефонах и медленных соединениях.
- Сохраняйте сайт статическим и без лишних библиотек, внешних запросов и тяжёлых ресурсов.
- Оптимизируйте изображения и проверяйте размер первой загрузки перед добавлением новых материалов.
- Сохраняйте рабочие фильтры, карточки, избранное и диалоги при изменениях.
- Не выдумывайте цены, состав, наличие, адрес, часы работы, контакты и сведения об операторе; неподтверждённое помечайте для уточнения.
- Перед публикацией проверьте мобильный вид, ссылки, консоль браузера и реальную загрузку всех ресурсов.

## Текущее состояние

- Разметка, стили и логика сайта находятся в `index.html`; изображения лежат отдельно в `images/`.
- Нет сборки, серверной части или внешних зависимостей.
- `index.html` занимает около 46 КБ; изображения занимают около 1,5 МБ суммарно и загружаются отдельными файлами. Изображения карточек загружаются по мере прокрутки. Перед добавлением новых изображений сжимайте их.
- Адрес страницы и контент требуют проверки владельцем перед коммерческой публикацией.
