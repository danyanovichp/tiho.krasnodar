# ТИХО — мини-каталог

Статический mobile-first сайт: HTML, CSS и vanilla JavaScript. Подходит для загрузки в Replit как Static/HTML проект. Точка входа — `index.html`; сборка и серверная часть не нужны.

## Локальный просмотр

Откройте `index.html` в браузере или используйте любой статический сервер. Для Replit выберите статический сайт и укажите корень проекта.

## Структура

- `index.html` — одностраничная витрина и диалоги карточек/документов.
- `styles.css` — адаптивная сетка, оформление и CSS-визуалы продуктов.
- `app.js` — каталог, фильтры, карточки, свайп/поворот, избранное в localStorage, юридические шаблоны.

## Перед публикацией

1. Подтвердить наличие позиций, описания и цены (включая цену кебаба).
2. Заменить CSS-визуалы фотографиями реальных продуктов по мере готовности.
3. Заполнить адрес, часы, контакты и реквизиты оператора/продавца.
4. Проверить практику обработки данных хостингом и актуализировать юридические тексты под неё.
5. Если появятся формы, заказ, платежи, аналитика, карта или сторонние cookie — до включения пересмотреть согласия, политику, уведомления и настройки передачи данных.

В проекте намеренно нет заказа, оплаты, форм, аналитики и сторонних cookie.
