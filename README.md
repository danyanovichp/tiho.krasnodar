# ТИХО — свежая пахлава. Маленькие радости.

Лёгкий статический сайт-витрина пальчиковой пахлавы с кешью. Продажа коробками, самовывоз: Краснодар, Сенной рынок, место № 8, возле конфет. Полное меню точки на Героя Сарабеева, 5к5 сохранено отдельно.

## Запуск

Откройте `index.html` или запустите `python3 -m http.server 8000` и перейдите на `http://localhost:8000`.

## Структура

- `index.html`, `baklava.css`, `baklava.js` — главная страница пахлавы и подготовленная форма предзаказа.
- `sarabeeva.html` — прежнее меню с фильтрами, карточками, избранным и диалогами. Доставка временно скрыта.
- `images/` — оптимизированные локальные фотографии и иконка из логотипа владельца.
- `AGENTS.md` — обязательные правила работы для разработчиков и ИИ-агентов.

## Главный приоритет

Быстрая загрузка и лёгкая работа на телефонах и медленных соединениях. Без сборки, фреймворков, внешних шрифтов и лишних запросов. Сжимайте изображения и сохраняйте адаптивность.

## Планы самовывоза

Цена: **300 ₽ за коробку**. Посетитель выбирает сегодня/завтра и 1–20 коробок. Контакты не запрашиваются. Это ориентир спроса, не бронь.

Google Таблица владельца: https://docs.google.com/spreadsheets/d/19fZ-bLDrnJ99Fl0NCMYmGoCMpF5bYbEvqN2iUJxIQvA/edit

Подготовлены `integrations/google-sheets/Code.gs` и `Form.html`. Форма работает внутри iframe Google Apps Script и сохраняет данные через `google.script.run`; подтверждение только после ответа сервера. Локально хранится случайный ID заявки на день, чтобы повторная отправка обновляла строку. Данные таблицы не публикуются. Люди могут передумать или отправить заявки с разных устройств: итог приблизительный.

**Статус: Google Apps Script опубликован, адрес подключён в `site-config.js`.** Реальная запись в таблицу и сводку проверена; повторное изменение 2 → 3 коробки обновляет одну строку. Изменения конфигурации сайта нужно отправить в GitHub Pages для работы на публичном домене. Telegram и онлайн-оплата не требуются. Инструкция обновления — `integrations/google-sheets/SETUP.md`.
